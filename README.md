# nuPhase
Package to perform phase space analysis for long baseline neutrino oscillation experiments

# Installation
Git clone this repository then you can install nuPhase using pip:

```
git clone git@github.com:ewanwm/nuPhase.git

pip install ./nuPhase/
```

# Usage 

After installing, you will have access to the main `nuPhase` app.
This app has many options and is highly configurable. To see the varius options you can do 

```
nuPhase -h
```
