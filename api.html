class nuPhase.event.Event(mode: int, e_nu: float, nu_pdg: int)

represents a single event (really a single neut interaction)

add_particle(particle: Particle) → None

Add a single particle to the event

Parameters:

particle (Particle) – particle to add

add_particles_from_arrays(pdg: array, energies: array, px: array, py: array, pz: array) → None

Add a number of particles to the event

All arrays must have the same shape (which should be 1D with length == num of particles)

Parameters:

  • pdg (np.array) – PDG codes for each particle

  • energies (np.array) – energies of each particle

  • px (np.array) – x momenta

  • py (np.array) – y momenta

  • pz (np.array) – z momenta

get_var(var: str)

ValueError if variable is not one of the standard ones and is not in the aux variable dictionary for this event
